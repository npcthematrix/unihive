# OMNI 板块数据面板重构设计

## 概述

将 OMNI 板块数据标签页拆分为三个子标签页，采用与"配置信息"标签页一致的子标签页模式。

## UI 结构

```
OMNI板块数据 (主标签页)
├── 板块查询 (子标签页)
│   ├── 搜索栏：关键词输入 + 筛选条件
│   ├── 搜索按钮
│   └── 结果列表 + 成分股展开
├── 同步管理 (子标签页)
│   ├── 同步控制区：数据源 + 板块类型 + 同步按钮
│   └── 同步状态：当前进度 + 上次同步时间
└── 数据统计 (子标签页)
    ├── 统计卡片网格
    └── 同步日志列表
```

## 组件设计

### 1. 板块查询

| 组件 | 说明 |
|------|------|
| 搜索栏 | 关键词输入框，支持板块名称/代码模糊搜索 |
| 筛选条件 | 下拉选择：数据源(fuyao/mootdx2)、板块类型(行业/概念) |
| 搜索按钮 | 点击触发查询 |
| 结果列表 | 板块卡片：名称、代码、类型、成分股数 |
| 成分股展开 | 点击板块卡片展开成分股列表 |

### 2. 同步管理

| 组件 | 说明 |
|------|------|
| 数据源选择 | 下拉：全部 / fuyao / mootdx2 |
| 板块类型选择 | 下拉：全部 / 行业板块 / 概念板块 |
| 同步按钮 | 触发同步，显示"同步中..."状态 |
| 状态显示 | 上次同步时间 |

### 3. 数据统计

| 组件 | 说明 |
|------|------|
| 统计卡片 | 数据源 + 板块类型 → 板块数、股票数 |
| 同步日志 | 时间、来源、类型、状态、记录数 |

## API 设计

### 查询 API

```
GET /api/omni/query
  ?source=fuyao|mootdx2
  &board_type=industry|concept
  &keyword=xxx
  &limit=100

Response:
{
  "sectors": [
    {
      "id": 1,
      "source": "mootdx2",
      "board_type": "industry",
      "code": "xxx",
      "name": "板块名称",
      "stock_count": 100
    }
  ],
  "total": 10
}
```

### 同步 API

```
POST /api/omni/sync
Body: { "source": "all", "board_type": "all" }

Response:
{ "status": "success", "message": "..." }
```

### 统计 API

```
GET /api/omni

Response:
{
  "stats": [{ "source": "mootdx2", "board_type": "industry", "sector_count": 67, "total_stocks": 386289 }],
  "recent_logs": [...]
}
```
