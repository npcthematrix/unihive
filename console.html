接入指南

1. 快速开始

UniHive MCP 是一个统一的金融数据网关，把通达信、同花顺、Tushare 等多个数据源聚合在同一个 MCP 接口后面。

1.1 启动网关

网关默认以 HTTP 模式启动（推荐），同时也支持 STDIO 模式。在项目根目录下运行：

.\scripts\start_all.ps1

启动后，控制台默认监听 http://127.0.0.1:18080，HTTP 网关（同时启用）监听 http://127.0.0.1:18081/mcp。

1.2 配置文件

上游数据源在 config/upstreams.yaml 中配置。修改后需要重启网关生效。

2. 接入方式

2.1 HTTP 模式（推荐）

网关以 Streamable HTTP 模式对外提供 MCP 接口，监听 http://127.0.0.1:18081/mcp。运行 .\scripts\start_console.ps1 会同时启动控制台和 HTTP 网关。

Claude Desktop / Cursor 配置：

{
  "mcpServers": {
    "unihive": {
      "url": "http://127.0.0.1:18081/mcp"
    }
  }
}

Python SDK 示例：

import asyncio
from fastmcp.client import Client

async def main():
    async with Client("http://127.0.0.1:18081/mcp") as client:
        tools = await client.list_tools()
        result = await client.call_tool("get_realtime_quote", {"symbol": "600000"})
        print(result.data)

asyncio.run(main())

2.2 STDIO 模式（备选）

用于不支持 HTTP MCP 的旧客户端，或本地脚本场景。需要单独启动 gateway 进程：

{
  "mcpServers": {
    "unihive": {
      "command": "python",
      "args": ["-m", "src.gateway_server", "--transport", "stdio"],
      "cwd": "D:/fintech_workspace/unihive"
    }
  }
}

或命令行单独启动 STDIO 模式：

python -m src.gateway_server --transport stdio

4. 常用示例

4.1 Python SDK（推荐）

通过 FastMCP 客户端连接 HTTP 网关（默认 http://127.0.0.1:18081/mcp）。所有 tool 名、参数和返回结构以 "MCP APIs" 标签页为准。

import asyncio
from fastmcp.client import Client

GATEWAY_URL = "http://127.0.0.1:18081/mcp"

async def main():
    async with Client(GATEWAY_URL) as client:
        # 1) 列工具名
        tools = await client.list_tools()
        print("available tools:", [t.name for t in tools])

        # 2) 调用实时行情（任意上游的 tool 都能这样调）
        quote = await client.call_tool(
            "get_realtime_quote",
            {"symbol": "sh600519"}
        )
        print(quote.data)

asyncio.run(main())

4.2 日 K 线（含日期范围）

bar = await client.call_tool(
    "get_daily_bar",
    {"symbol": "sh600519", "start_date": "20260101", "end_date": "20260301"}
)
print(bar.data)

4.3 搜索股票

match = await client.call_tool(
    "search_stock",
    {"keyword": "茅台"}
)
print(match.data)
提示：如果你的客户端只支持 stdio，启动 STDIO 模式： python -m src.gateway_server --transport stdio。 调试可用 MCP Inspector（npx -y @modelcontextprotocol/inspector），Python 可用官方 SDK（from mcp import ClientSession, StdioServerParameters）。Windows 下 cwd 用项目绝对路径。

5. 故障排查

5.1 连接失败

  • 检查网关是否已启动：访问 http://127.0.0.1:18080
  • 检查客户端配置中的 cwd 路径是否正确
  • Windows 下确认 Python 已加入 PATH

5.2 接口返回错误

  • 查看控制台"上游状态"标签页，确认对应上游是否在线
  • 查看返回的 last_error 字段
  • 对应上游若被禁用，需修改 config/upstreams.yaml 并重启

5.3 参数错误

  • 股票代码由网关自动标准化（000001、sh600519、600519.SH、sz000001 都能识别
  • 日期统一使用 YYYYMMDD（如 20260301）
  • 具体参数以 "MCP APIs" 标签页每个 tool 行的"详情"展开为准

5.4 反馈渠道

遇到问题请提交 Issue 到 github.com/unihive/unihive,并附上控制台截图与接口返回内容。点击 "MCP APIs" → 对应 tool 行 → 复制 按钮即可拿到完整 tool 名与参数。
