1. 快速开始

                    
UniHive MCP 是一个统一的金融数据网关，把通达信、同花顺、Tushare 等多个数据源聚合在同一个 MCP 接口后面。


                    
1.1 启动网关

                    
在项目根目录下运行：

                    

                        
                        
.\scripts\start_all.ps1

                    

                    
启动后，控制台默认监听 http://127.0.0.1:18080，网关以 stdio 方式对外提供 MCP 接口。


                    
1.2 配置文件

                    
上游数据源在 config/upstreams.yaml 中配置。修改后需要重启网关生效。


                    
2. 接入方式


                    
2.1 HTTP 模式（推荐）

                    
网关以 Streamable HTTP 模式对外提供 MCP 接口，监听 http://127.0.0.1:18081/mcp。运行 .\scripts\start_console.ps1 会同时启动控制台和 HTTP 网关。


                    
Claude Desktop / Cursor 配置：

                    

                        
                        
{
  "mcpServers": {
    "unihive": {
      "url": "http://127.0.0.1:18081/mcp"
    }
  }
}

                    


                    
Python SDK 示例：

                    

                        
                        
import asyncio
from fastmcp.client import Client

async def main():
    async with Client("http://127.0.0.1:18081/mcp") as client:
        tools = await client.list_tools()
        result = await client.call_tool("get_realtime_quote", {"symbol": "600000"})
        print(result.data)

asyncio.run(main())

                    


                    
2.2 STDIO 模式（备选）

                    
用于不支持 HTTP MCP 的旧客户端，或本地脚本场景。需要单独启动 gateway 进程：

                    

                        
                        
{
  "mcpServers": {
    "unihive": {
      "command": "python",
      "args": ["-m", "src.gateway_server", "--transport", "stdio"],
      "cwd": "D:/fintech_workspace/unihive"
    }
  }
}

                    

                    
或命令行单独启动 STDIO 模式：

                    

                        
                        
python -m src.gateway_server --transport stdio

4. 常用示例


                    
4.1 获取实时行情

                    

                        
                        
import asyncio
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

async def main():
    params = StdioServerParameters(
        command="python",
        args=["-m", "mcp_data_gateway.gateway_server"],
        cwd="D:/fintech_workspace/unihive"
    )
    async with stdio_client(params) as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()
            result = await session.call_tool(
                "get_realtime_quote",
                {"symbol": "600000"}
            )
            print(result.content[0].text)

asyncio.run(main())

                    


                    
4.2 获取日 K 线

5. 故障排查


                    
5.1 连接失败

                    
    
                        
  • 检查网关是否已启动：访问 http://127.0.0.1:18080
    • 
                        
  • 检查客户端配置中的 cwd 路径是否正确
    • 
                        
  • Windows 下确认 Python 已加入 PATH
    • 
                    


                    
5.2 接口返回错误

                    
    
                        
  • 查看控制台"上游状态"标签页，确认对应上游是否在线
    • 
                        
  • 查看返回的 last_error 字段
    • 
                        
  • 对应上游若被禁用，需修改 config/upstreams.yaml 并重启
    • 
                    


                    
5.3 参数错误

                    
    
                        
  • 股票代码需要标准化（参见 src/normalizer.py）
    • 
                        
  • 日期格式统一为 YYYYMMDD
    • 
                    


                    
5.4 反馈渠道

                    
遇到问题请提交 Issue 到项目仓库，并附上控制台截图与接口返回内容。
